# FastAudio

ElevenLabs voiceover ko tez karne ka tool. Pitch same rehti hai, sirf bolne ki speed badhti hai (jaise `ffmpeg -af atempo=1.25`).

**Use karo:** https://xerocodeindia-creator.github.io/fastaudio/

1. MP3 / WAV / M4A file daalo
2. Speed chuno (default 1.25x)
3. "Tez karo" dabao, sun ke check karo
4. MP3 ya WAV download karo

Sab kuch browser mein hota hai. File kahin upload nahi hoti.

Files: `index.html` (tool), `lame.min.js` (MP3 encoder, lamejs 1.2.1, LGPL).
